# Security

[The security model](docs/SECURITY.md) covers backend controls, frontend obligations and
consumer token handling. [The public contract](docs/PUBLIC-INTERFACE.md#export-and-versioning)
defines experimental export conditions.

There are no releases or supported deployments. Report design and implementation problems
through an issue. [The review requirements](docs/SECURITY.md#accessibility-and-review) cover
matching, identity and credential lifetimes. [Testing](docs/TESTING.md) records
fixture and real-hardware evidence. A disclosure contact and window remain to be defined
before deployment.
